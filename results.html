Benchmark Results

This section documents the results of the benchmarking phase, where the eight-node CPU-based cluster running John the Ripper (JtR Jumbo with MPI) is compared against a standalone GPU system. The primary objective is to evaluate password‑cracking throughput, efficiency, and scalability across the two approaches.

Benchmarking Methodology

All tests were conducted using identical hash samples to ensure consistency. The cluster executed JtR with OpenMPI across all eight nodes, while the GPU system ran JtR in standalone mode. Each test measured:

  • Execution Time — total time required to complete the cracking attempt
  • Hash Throughput — measured in hashes per second (H/s)
  • Resource Utilization — CPU usage, GPU usage, and networking overhead
